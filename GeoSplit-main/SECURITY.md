# Security Policy

## Supported versions

Security fixes are applied to the latest GeoSplit release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a vulnerability that could risk user data or filesystem safety.

Include the affected version, operating system, reproduction steps, and expected impact. Reports will be acknowledged as soon as practical.

GeoSplit never intentionally follows output paths outside the selected directory. Reports involving path traversal, unsafe replacement, transaction recovery, or malformed input are especially important.
